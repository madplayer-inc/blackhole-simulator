# 개발 범위와 스택

## 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 플랫폼 | 웹 (브라우저, WebGL2) | 설치 없이 실행, 공유 쉬움 |
| 언어/빌드 | TypeScript + Vite 7 | 빠른 개발 서버, 타입 검사 |
| 3D | Three.js r187 (ShaderMaterial 직접 작성) | 렌즈 효과를 모든 물체의 정점 셰이더에서 공통 처리 |
| 후처리 | UnrealBloomPass | 원반·광자 고리 발광 |
| 패널 | Tweakpane 4 | 슬라이더·토글·읽기 전용 모니터를 한 패널에 |
| 물리 | CPU, Float32Array 기반 적분 | 입자 수만 개까지 프레임당 수 ms |

## v0.1 범위 (현재)

- Kerr 블랙홀 반경·열역학 값 (정확한 식)
- 의사뉴턴 + 중력자기 근사 궤도 역학, 입자별 적응 시간 간격
- 행성 3종 기본 배치 + 사용자 정의 행성 투입 (반지름, 질량비, 근점, 이심률, 경사, 역행)
- 조석 유출 → 조석 파괴 → 파편 흐름 → 원반 형성 → ISCO 안쪽 낙하 → 흡수·질량 증가
- 3D 격자 (강물 모형), 흐름 펄스, 흐름 입자, 프레임 끌림 꼬임
- 얇은 렌즈 근사 1·2차 상, 그림자, 광자 고리, 도플러 비밍·적색편이
- 정확한 Kerr 그림자 윤곽(D자형)과 포톤 링, 광자 껍질 3D 도식, 구형 광자 궤도 애니메이션 (v0.2)
- 정확한 Kerr 강물 모형으로 흐르는 격자(구면 컨베이어 / 직교 교차 페이드)와 정확한 프레임 드래깅 꼬임 (v0.3)
- 한국어·영어, 글래스 dock(WebGL 굴절·블러 + 호버 중력 렌즈), 장면·카메라 프리셋, 공유 링크, 스크린샷, 모바일 레이아웃, GitHub Pages 배포 설정 (v0.4)
- 지수형 시간 배율 슬라이더 (10⁻² ~ 10⁴ GM/c³ / 실제 1초), 현실 단위 환산

## 다음 단계 후보

1. 화면 공간 측지선 광선 추적 (광자 고리 다중 상, 원반의 고차 상 — 그림자 윤곽은 v0.2에서 해석식으로 해결)
2. 파편 입자 GPU 계산 (WebGPU 컴퓨트) — 10⁵~10⁶ 입자
3. 파편 간 충돌·압력 (SPH 간이판) 으로 원반 형성의 현상론적 규칙 대체
4. 상대론적 제트 (Blandford–Znajek 출력 추정치 표시)
5. 관측자 시점: 블랙홀로 떨어지는 카메라 (시간 지연·청색편이 체험)
6. 장면 저장/불러오기, 녹화
