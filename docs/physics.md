# 물리 모델과 근사

단위: G = c = 1. 길이 단위 GM/c², 시간 단위 GM/c³ (초기 질량 M₀ = 1 기준). 스핀 축 = +Y.
현실 단위 환산은 `질량 log₁₀(M☉)` 값으로만 바뀌고, 시뮬레이션 동역학에는 영향이 없다 (일반상대론은 질량에 대해 스케일 불변).

## 블랙홀 특성 반경 (정확한 Kerr 해) — `src/physics/kerr.ts`

| 양 | 식 |
|---|---|
| 사건의 지평선 | r₊ = M(1 + √(1−χ²)) |
| ISCO (순/역행) | Bardeen–Press–Teukolsky 1972 |
| 광자 궤도 (적도, 순/역행) | r = 2M{1 + cos[⅔ arccos(∓χ)]} |
| 에르고구 | r_E(θ) = M + √(M² − a²cos²θ) |
| 그림자 윤곽 | Bardeen 임계 곡선 (아래 "그림자와 광자 껍질") |
| 호킹 온도 | T = ħc³/(GMk) · √(1−χ²) / (4π(1+√(1−χ²))) |
| 엔트로피 | S/k = A/4ℓ_P², A_Kerr = 8πMr₊ |
| 증발 시간 | ≈ 2.1×10⁶⁷ 년 (M/M☉)³ (비회전, 근사) |

## 운동 방정식 (근사) — `src/physics/sim.ts`

- **반경 방향 중력**: Artemova–Björnsson–Novikov(1996) 의사뉴턴 힘
  F(r) = M / (r^(2−β)(r − r₊)^β), β = r_ISCO/r₊ − 1.
  χ = 0이면 Paczyński–Wiita 퍼텐셜과 같고, ISCO(순행)와 지평선 위치를 Kerr 값과 맞춘다.
- **프레임 끌림**: 약한장 중력자기(Lense–Thirring) 가속도 a = 2v × [J − 3(J·r̂)r̂]/r³ 를 더한다 (토글 가능).
  ABN 힘이 이미 스핀 효과 일부를 담고 있어 순행 궤도에서는 약간 이중 계산된다.
- **적분기**: 입자별 적응 시간 간격 KDK 립프로그. 한 프레임당 입자 하나에 최대 400 하위 단계.
  넘치면 그 입자는 그 프레임에서 시간이 덜 흐른다 (패널 `성능`에 "지연 입자"로 표시).
- 행성끼리, 파편끼리의 자체 중력은 없다 (모두 시험 입자).

## 조석 파괴

- 조석 반경 r_t = R(M/m)^(1/3), 조석 변수 χ = (r_t/r)³.
- χ > 0.5: 안쪽·바깥쪽 라그랑주점에서 질량 유출. 행성은 반경 방향으로 늘어나 보인다 (스파게티화 시각화).
- χ ≥ 1: 남은 질량 전체를 파편 입자로 바꾼다. 파편은 행성 속도 + 조석 고정 자전 속도를 물려받고,
  이후 늘어남은 차등 중력만으로 생긴다.
- 시뮬레이션의 행성 크기는 보이도록 과장되어 있다. 현실 값은 패널 `물리량`의 지구형 행성·태양형 별 r_t를 본다
  (예: 약 10⁸ M☉ 이상이면 태양형 별은 파괴되기 전에 통째로 삼켜진다).

## 강착 원반 형성 (현상론적)

- 파편이 근점을 한 번 지나면 "원반 상태"가 된다 (흐름의 자기 교차·충격을 대신하는 단순 규칙).
- 원반 상태 입자의 속도를 평균 원반면의 원궤도 속도 쪽으로 감쇠: 감쇠율 = 점성 α × Ω.
- 안쪽 유입: 원궤도보다 약간 느린 접선 목표 속도로 각운동량을 빼서 유입 속도 v_in = (유입 계수)·v_c 를 만든다.
- ISCO 안쪽에서는 지지력이 없어 그대로 낙하한다. r < 1.02 r₊ 이면 흡수되고, 질량에 더해진다 (토글).
- 온도 분포: T ∝ r^(−3/4)(1 − √(r_in/r))^(1/4) (Shakura–Sunyaev/Novikov–Thorne 형태).
  관측 색은 도플러 인자 δ와 중력 적색편이 √(1−2M/r)로 이동하고, 밝기는 (δg)^4에 비례한다.

## 시공간 격자 — Kerr 강물 모형 (정확한 식) — `src/physics/river.ts`, `src/render/grid.ts`

- "흐르는 공간" = 무한히 먼 곳에서 정지 상태로 놓아 떨어뜨린 각운동량 0 관측자들 (E = 1, L = 0, Q = 0).
  이들은 θ를 유지하며 dr/dτ = −√(2r(r²+a²))/ρ² 로 떨어진다 (ρ² = r² + a²cos²θ, M = 1). a = 0이면 Painlevé 강물 v = √(2M/r).
- 남은 낙하 시간: F(r, θ) = I1(r) + a²cos²θ·I0(r). 1차원 표 두 개(I1, I0)를 GPU 텍스처로 넘기고, 셰이더에서 뉴턴법으로 역함수 r(F)를 구한다.
- 프레임 드래깅: Kerr–Schild 직교 좌표(지평선에서 정칙, 멀리서 평탄)에서 낙하자가 도는 각
  dΦ/dr = −(a/(r²+a²))·x/(1+x),  x = √(2r/(r²+a²)). 무한대부터의 누적각 G(r)를 표로 쓴다.
  멀리서는 (2/3)a√2 r^(−3/2) (약한장 Lense–Thirring)과 같다.
- 검증: a = 0 낙하 시간이 해석해와 0.002% 이내, 독립 측지선 적분과 꼬임각 0.2147 vs 0.2149 rad (a = 0.9, r 40 → r₊+0.05).
- 실제 꼬임각은 작다: 무한대 → 지평선 전체가 a = 0.6에서 7.2°, a = 0.9에서 12.9°, a = 0.998에서 18.0°. 대부분 r < 5M에서 생긴다.
  `프레임 끌림 배율`로 키워 볼 수 있다 (1 = 실제).
- 주의: 꼬임의 크기는 시간 단면(좌표) 선택에 따라 달라진다. Boyer–Lindquist φ에서는 지평선까지 무한히 감기고,
  Doran 좌표에서는 낙하자가 전혀 돌지 않는다 (이때 프레임 드래깅은 국소 관성계의 회전으로만 나타난다).
  좌표와 무관한 값은 패널의 지평선 각속도 Ω_H = a/(2Mr₊)와 ZAMO 각속도 ω = 2Mar/[(r²+a²)² − a²Δsin²θ].
- 구조:
  - 구면: 남은 낙하 시간이 같은 껍질들이 컨베이어처럼 안쪽으로 이동하고 바깥에서 다시 생긴다. 바큇살은 흐름선 자체다.
    a ≠ 0이면 껍질은 위도에 따라 낙하 시간이 달라 살짝 납작하다.
  - 직교 / 적도면: 균일한 격자의 낙하자를 한꺼번에 놓고, 반 주기 어긋난 두 벌을 sin²/cos² 가중으로 교차 페이드한다.
    격자 칸이 안쪽에서 반경 방향으로 늘어나고 옆으로 좁아지는 것이 공간의 조석 변형이다.
- 색: 정지 관측자의 시간 지연 √(1 − 2Mr/ρ²). 에르고 표면에서 0이 되어 그 안에서는 정지가 불가능함을 뜻한다.
- 펄스는 낙하자와 함께 움직인다 (위상 = 남은 낙하 시간 + 시계). 흐름 재생 속도는 본 시계와 따로이고, 동기화할 수 있다.

## 중력 렌즈 (근사)

- 정점 셰이더에서 얇은 점 렌즈 근사: θ± = (β ± √(β² + 4θ_E²))/2, θ_E² = 4M·D_ds/(D_d·D_s).
- 1차 상과 반대편 2차 상을 모두 그린다. 상이 Kerr 그림자 윤곽 안으로 떨어지면 그리지 않는다
  (윤곽은 64방향 반경표로 셰이더에 넘긴다).
- 약한장 근사라서 광자 고리 근처의 다중 상(고차 상)은 재현하지 않는다. 그림자 모양 자체는 아래의 정확한 식을 쓴다.

## 그림자와 광자 껍질 (정확한 Kerr 식) — `src/physics/photon.ts`

- 구형 광자 궤도: 반경 r에서 보존량
  ξ = (r²(3−r) − a²(r+1)) / (a(r−1)),  η = r³(4a² − r(r−3)²) / (a²(r−1)²)   (M = 1)
- 광자 껍질: 이 궤도들이 차지하는 영역. r는 적도 순행 광자 궤도 ~ 역행 광자 궤도 사이이고,
  각 r에서 위도는 cos²θ ≤ P(r)까지 (P = θ 방정식의 근). 극까지 가는 것은 ξ = 0인 반경 하나뿐이다.
  화면에는 렌즈 변형 없이 실제 좌표(√(r²+a²) sinθ, r cosθ)의 3D 도식으로 그린다.
- 광자 궤도 애니메이션: Kerr 영측지선을 그대로 적분한다. cosθ = √P sinψ 치환으로 전환점이 없는 식
  dψ/dλ = a√(P sin²ψ + Q), dφ/dλ = −(a − ξ/sin²θ) + a(r²+a²−aξ)/Δ, dt/dλ = −a(a sin²θ − ξ) + (r²+a²)(r²+a²−aξ)/Δ.
  재생 속도는 본 시계와 별도 슬라이더다. 이 궤도들은 불안정해서 실제로는 조금만 어긋나도 탈출하거나 떨어진다.
- 그림자 윤곽 (먼 관측자, 경사각 θo): α = −ξ/sinθo,  β = ±√(η + a²cos²θo − ξ²cot²θo).
  유한 거리 D의 카메라에서는 각 점의 시직경을 asin(b/D)로 맞춘다.
- 검증 값: a = 0 → 반경 5.196M 원. a = 0.998, 옆에서(90°) → α ∈ [−2.11, 7.00]M, 높이 10.39M.
  a = 0.6, 극에서 → 반경 약 5.09M 원. 다가오는 쪽(순행 광자 쪽)이 평평해진다.
- 포톤 링 발광은 이 윤곽을 따라가는 띠로 그린다 (밝기 분포는 시각용 근사).
